# MetroMate Subscription

This folder contains all files, documentation, and service details related to the MetroMate Subscription.

## Folder Structure

| Folder / File | Description |
|---|---|
| `docs/` | Documentation files and guides |
| `b2b/` | B2B service offerings, proposals, and agreements |
| `b2c/` | B2C service offerings, user flows, and plans |
| `assets/` | Images, logos, and media assets |

## Overview

- **B2B Services**: Business-to-business subscription packages, partnerships, and enterprise offerings.
- **B2C Services**: Consumer-facing subscription plans, pricing, and onboarding flows.
- **Docs**: All internal documentation, roadmaps, and update logs.
